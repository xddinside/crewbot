## How the pieces fit

| Layer | What it does | Where to configure it |
|---|---|---|
| **Bot** | Holds the identity, conversation, memory, and defaults | Bot settings |
| **Agent engine** | Runs the reasoning loop and tools | Model picker and App settings |
| **Working folder** | Gives the bot project context and a safe place to work | Bot settings |
| **Connected apps** | Authorizes services such as Gmail or GitHub | Connected apps |
| **Computer** | Gives visual control of a desktop environment | Computer panel |
| **Automation** | Runs a task later, on a schedule, or from a webhook | Automations |

<Callout type="warn" title="Linux-first support">
  Linux is the only supported platform during active development. Arch Linux is the daily development target; Ubuntu 24.04 x86_64 is the package and CI reference. Linux installed continuity and recovery acceptance remains pending. Native Android, iOS, macOS, and Windows support is parked, and its proof is deferred rather than passed. Linux CI also stages a Cloudflare connector for ARM64, which does not establish ARM64 desktop support. See the [platform support policy](https://github.com/xddinside/crewbot/blob/main/docs/platform-support.md).
</Callout>
